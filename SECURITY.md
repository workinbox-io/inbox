# Security policy

Please report vulnerabilities privately through GitHub:
[Report a vulnerability](https://github.com/workinbox-io/inbox/security/advisories/new). Don't open a public issue.

Include what is affected, how to reproduce it and the impact you expect. We'll acknowledge the report within a few
days and keep you posted until it's fixed. Fixes ship to workinbox.io first; self-hosters get them by updating to the
latest `main`.
